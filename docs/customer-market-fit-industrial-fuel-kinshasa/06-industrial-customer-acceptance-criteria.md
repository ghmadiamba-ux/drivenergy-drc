# 06 - Critères d'acceptation client industriel

Date : 2026-05-28

## Ce qu'un client sérieux demandera

| Exigence | Pourquoi | Statut DrivEnergy actuel |
|---|---|---|
| Fiche technique produit | décision technique et achat | à créer après production |
| Analyse laboratoire | vérifier qualité, sécurité, conformité | ouverte |
| MSDS / FDS | stockage, HSE, responsabilité | à créer |
| Pouvoir calorifique | comparer coût énergétique | à mesurer |
| Viscosité | compatibilité brûleur/pompe | à mesurer |
| Point éclair | sécurité stockage/manutention | à mesurer |
| Soufre | émissions/corrosion | à mesurer |
| Chlore | risque PVC/HCl/corrosion | critique, à mesurer |
| Eau/sédiments | stockage, combustion, buses | à mesurer |
| Stabilité stockage | éviter séparation/wax | à tester |
| Test brûleur | preuve pratique | à préparer |
| Responsabilité incident | protection client | à cadrer juridiquement |
| Approvisionnement régulier | usage au-delà du test | pas prêt |
| Prix avantageux | raison économique d'accepter le risque | à définir après coûts |

## Conditions commerciales probables

Un client acceptera un fuel alternatif seulement si :

- prix inférieur au combustible actuel ;
- risque opérationnel faible ;
- test petit volume possible ;
- disponibilité régulière après test ;
- responsabilité claire ;
- bénéfice économique mesurable.

## Seuil de communication

Avant client : ne pas dire “remplacement”. Dire :

**test de substitution partielle contrôlée pour usage thermique industriel stationnaire**.
