# 08 - Registre des risques marché/client

Date : 2026-05-28

| Risque | Sévérité | Mitigation | Prochaine action |
|---|---|---|---|
| Client refuse fuel non standard | Élevée | commencer par clients flexibles, test limité | identifier savonnerie/agro-industrie |
| Huile trop variable | Critique | libération par lot, analyse labo | définir specs minimum |
| Chlore/PVC | Critique | exclusion PVC + test chlore | intégrer seuil No-Go |
| Viscosité incompatible | Élevée | filtration, préchauffage, mélange | mesurer viscosité 40 °C |
| Brûleur encrassé | Élevée | test petit volume, filtration fine | utiliser brûleur non critique |
| Émissions / fumées | Critique | analyse fumées si possible | protocole HSE test |
| Stockage dangereux | Critique | MSDS, rétention, ventilation | définir conditions cuve |
| Incident chez client | Critique | contrat test, responsabilité claire | aucun test sans protocole signé |
| Prix pas attractif | Élevée | benchmark prix livré réel | collecte terrain prix combustible |
| Volume DrivEnergy insuffisant | Moyenne | test seulement, pas promesse supply | communiquer volume pilote |
| Pas de laboratoire local | Moyenne | identifier labo RDC/région | chercher laboratoires carburant |
| Mauvais premier test | Critique | choisir client moins exposé | éviter grande brasserie en premier |
