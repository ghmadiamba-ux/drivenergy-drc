# 07 - Protocole de test client industriel

Date : 2026-05-28

## Phase A - Préqualification client

| Action | Donnée à collecter | Go/No-Go |
|---|---|---|
| Identifier équipement | chaudière, four, brûleur, modèle | No-Go si équipement critique sans bypass |
| Identifier combustible actuel | type, prix, fournisseur, consommation | Go si fuel/gasoil/heating oil liquide |
| Vérifier stockage | cuves, rétention, sécurité | No-Go si stockage dangereux |
| Vérifier technicien disponible | opérateur brûleur/maintenance | No-Go sans responsable technique |
| Définir objectif test | flamme, chaleur, mélange, coût | Go si objectif limité |

## Phase B - Analyse huile

Tests minimum :

- PCI.
- Densité.
- Viscosité.
- Point éclair.
- Eau/sédiments.
- Soufre.
- Chlore.
- Cendres.
- Acidité si possible.

No-Go immédiat si chlore élevé, eau/sédiments élevés, point éclair dangereux ou instabilité forte.

## Phase C - Test contrôlé

1. Petit volume : 20-50 L pour test brûleur hors ligne si possible.
2. Filtration fine avant test.
3. Mélange initial : 5-10% huile pyrolyse dans combustible actuel, sauf avis technicien.
4. Mesurer : flamme, fumée, odeur, température, pression, dépôts, bruit pompe.
5. Arrêt immédiat si fumée noire excessive, flamme instable, colmatage, odeur anormale, surchauffe.
6. Ne pas alimenter un process critique en continu au premier test.

## Phase D - Rapport

Le rapport doit conclure :

- compatible / incompatible / test supplémentaire ;
- modifications brûleur requises ;
- filtration/préchauffage requis ;
- pourcentage mélange acceptable ;
- prix acceptable ;
- volume potentiel ;
- risques HSE ;
- Go/No-Go test prolongé.
