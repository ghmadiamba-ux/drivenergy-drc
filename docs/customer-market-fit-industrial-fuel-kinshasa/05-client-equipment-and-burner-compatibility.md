# 05 - Équipements clients et compatibilité brûleurs/chaudières

Date : 2026-05-28

## Équipements typiques

| Équipement | Combustible habituel | Points de compatibilité | Risque avec huile pyrolyse | Test requis |
|---|---|---|---|---|
| Chaudière vapeur brûleur fuel | fuel oil, gasoil, HFO selon taille | viscosité, filtration, pression pompe, buse, flamme | encrassement, fumée, instabilité, dépôts | test petit volume + analyse fumées |
| Chaudière eau chaude | gasoil/fuel/GPL | similaire chaudière vapeur | odeur, fumée, sécurité | test brûleur encadré |
| Four industriel brûleur liquide | fuel/gasoil | tolérance parfois plus large | qualité flamme, dépôts, corrosion | test progressif |
| Brûleur diesel | diesel/gasoil | viscosité basse, point éclair, buses fines | colmatage si huile lourde/waxy | mélange faible % et filtration fine |
| Brûleur HFO | fuel lourd préchauffé | préchauffage, viscosité, pompes adaptées | huile trop légère/instable ou incompatibilité réglage | test avec technicien brûleur |
| Groupe électrogène diesel | gasoil | injection moteur très sensible | non recommandé phase 1 | à éviter |
| Système GPL | GPL | gaz, pression, brûleur dédié | non compatible liquide | non recommandé |

## Besoins techniques avant test

- Identifier fabricant et modèle de brûleur.
- Vérifier type de pompe et buse.
- Vérifier filtration actuelle.
- Vérifier préchauffage existant.
- Vérifier plage viscosité acceptable.
- Vérifier matériau joints/pompes.
- Prévoir arrêt immédiat si fumée noire, odeur forte, flamme instable, pression anormale.

## Règle DrivEnergy

Ne jamais tester l'huile de pyrolyse directement dans un équipement client critique. Commencer par :

1. analyse laboratoire ;
2. test brûleur hors ligne ou brûleur dédié si possible ;
3. mélange faible avec combustible actuel ;
4. supervision technicien client ;
5. rapport écrit.
