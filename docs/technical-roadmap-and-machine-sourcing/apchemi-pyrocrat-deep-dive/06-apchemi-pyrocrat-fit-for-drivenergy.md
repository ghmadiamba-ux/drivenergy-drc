# 06 - Compatibilité APChemi / Pyrocrat avec DrivEnergy

Date : 2026-05-28

## Score global

**Score APChemi / Pyrocrat : 68 / 100**

Comparaison : Beston = 58 / 100.

## Forces

- Plus technique et moins purement catalogue que Beston.
- Sources tierces fortes : Technip Energies, TDB-DST.
- Positionnement R&D / feedstock due diligence intéressant pour DrivEnergy.
- Expérience affichée sur exploitation, purification, ISCC Plus.
- Proximité Sud global / Inde potentiellement pertinente.

## Faiblesses

- Capacité 1 t/j non démontrée publiquement.
- Claims PET/PVC et energy self-sufficiency incompatibles avec prudence DrivEnergy s'ils ne sont pas recadrés.
- Peut pousser vers purification/pétrochimie/diesel/circular plastics, trop complexe pour phase 1.
- Clients souvent anonymes.
- Coût et support Kinshasa non vérifiés.

## Décision recommandée

APChemi / Pyrocrat mérite une **shortlist RFQ conditionnelle prioritaire**, devant Beston, mais seulement après validation feedstock/site/HSE. Le meilleur rôle initial pourrait être :

1. feedstock due diligence / test échantillons ;
2. pré-ingénierie 1-2 t/j ;
3. RFQ technique strict ;
4. fournisseur machine seulement si petite solution prouvée.
