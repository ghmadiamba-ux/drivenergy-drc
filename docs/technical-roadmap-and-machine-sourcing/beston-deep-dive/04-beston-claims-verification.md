## Vérification indépendante technique

- Revues académiques : pyrolyse plastique souvent autour de 400-550 °C pour polyoléfines, mais rendement dépend fortement température, temps de séjour, catalyse, condensation et feedstock.
- PVC : risque HCl/corrosion et chlore confirmé par littérature et sources HSE.
- PET : moins pertinent pour huile combustible stable ; risque produits oxygénés/acides.
- PE/PP : cohérents avec la stratégie DrivEnergy.

## Conclusion claims

Les claims Beston sont utiles pour cadrer les questions RFQ, pas pour décider un achat. Les deux claims les plus sensibles sont :

1. rendement PE/PP jusqu'à 80% ;
2. gaz réutilisé pour chauffage.

Ils doivent être transformés en exigences mesurables : bilan matière, bilan énergie, test sur feedstock PE/PP, vidéo active, FAT/SAT et analyses huile.
