## Note de méthode

Les sources fournisseurs sont utiles pour cadrer les questions RFQ, mais elles ne constituent pas des preuves suffisantes pour achat. Les seules preuves acceptables avant décision fournisseur seront : références actives vérifiées, vidéos live, FAT/SAT, données huile, bilans matière/énergie, documentation HSE et coût total rendu Kinshasa.
