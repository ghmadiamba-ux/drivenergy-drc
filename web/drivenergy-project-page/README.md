# DrivEnergy DRC Public Website

Launchable v1 homepage for DrivEnergy DRC.

## Stack

- React
- TypeScript
- Vite
- CSS

## Commands

```powershell
npm install
npm run build
npm run preview
```

## Deployment Notes

- Install dependencies with `npm install`.
- Create a production build with `npm run build`.
- Preview the production build locally with `npm run preview`.
- Expected output is the static Vite build in `dist/`.
- Contact email currently uses the placeholder `contact@drivenergy.cd`; confirm the real mailbox before public launch.

## Status

Public homepage v1 focused on industrial credibility, controlled plastic waste-to-industrial-fuel positioning, feedstock discipline, safety validation, roadmap, and partnership contact.
