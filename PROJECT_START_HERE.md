## Projet

DrivEnergy Kinshasa est un projet industriel semi-industriel a Kinshasa, RDC.

Objectif : transformer des plastiques usages controles en huile de pyrolyse plastique / fuel industriel technique / combustible industriel alternatif pour usages thermiques industriels prives.

Client prioritaire initial : brasserie privee ou autre industriel thermique a Kinshasa.

## Ce que le projet n'est pas

- Diesel automobile.
- Carburant routier.
- Raffinerie.
- Solution miracle.
- Technologie sans risque.
- Projet ONG.
- Projet dependant de l'Etat comme client principal.

## Strategie actuelle

- Technologie phase 1 : pyrolyse thermique batch robuste.
- Capacite initiale : 1 tonne/jour.
- Capacite future : 2 tonnes/jour seulement apres preuves.
- Feedstock : PE/PP majoritaire.
- PVC : exclusion stricte.
- PET : limite / conditionnel.
- Gaz non condensable : auto-alimentation partielle uniquement.
- Modele : own-and-operate local.
- Workforce : 100 % locale apres formation.
- Ordre d'execution : terrain avant fournisseur, fournisseur avant pilote, pilote avant scale.

## Statut courant

Statut : Go conditionnel de conception.

No-Go pour fournisseur, RFQ, FPI final ou pilote industriel tant que les validations terrain feedstock/site/HSE ne sont pas faites.
